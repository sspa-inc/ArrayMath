# ArrayMath

![ArrayMath logo](assets/arraymath-logo.png)

ArrayMath is a small command-line array/table calculator written in Fortran. It is intended to provide fast, scriptable operations similar to a focused subset of NumPy and Pandas: read numeric arrays, combine arrays, transform values, subset/filter rows and columns, compute column statistics, group rows, sort, transpose, stack, and write the result.

The tool processes options in command-line order. This is important: options that describe how to read a file, such as `-sr`, `-sc`, `-rn`, and `-cn`, must appear before the `-a` or `-m` option that reads that file. Transform options apply immediately to the current in-memory result.

With GNU make:

```sh
make
```

The executable is written to:

```text

```

Clean generated files:

```sh
make clean
```

On Windows, the batch helper also builds into `bin`:

```bat

```

## Basic Usage

```text
ArrayMath -d nrow ncol [options] -a arrayfile multiplyfile scale [options] [output]
```

Examples:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0
bin\ArrayMath.exe -d 4 3 -a data.dat - 2.0 -m *3 -o 1
bin\ArrayMath.exe -d 4 3 -cn -a named.dat - 1.0 -f id>=3 -s c2,3
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -x sum
```

If `output` is omitted, results are printed to stdout. If `output` is provided as the final argument, ArrayMath writes to that file.
By default, line endings use the Fortran compiler's normal output behavior. Use `--lf` to force LF (`\n`) endings in either destination.

## Data Model

ArrayMath stores data internally as a 2D real array with shape:

```text
nrow rows x ncol columns
```

The command line declares this shape with `-d nrow ncol`. Input files may use commas, tabs, or spaces between fields.

Optional row and column names are supported:

- `-rn` reads row names from the first non-skipped column.
- `-cn` reads column names from the first non-skipped row.
- Both can be used together for table-like data.

## Option Reference

### Required Shape

`-d nrow ncol`, `--dim nrow ncol`

Defines the shape of the array. This must be the first meaningful option because the program allocates the result array from these dimensions.

Example:

```bat
bin\ArrayMath.exe -d 10 5 -a data.dat - 1.0
```

### Add Input Array

`-a arrayfile multiplyfile scale`, `--add arrayfile multiplyfile scale`

Reads an array and adds it to the current result:

```text
result = result + array * scale
```

If `multiplyfile` is provided and is not `-`, ArrayMath reads a second array and multiplies element-by-element before scaling:

```text
result = result + array * multiply_array * scale
```

Use `-` for `arrayfile` to read from stdin. Use `-` for `multiplyfile` when no multiplier array is needed.
Piped input also supports row and column names when `-rn` and `-cn` precede `-a`.

```powershell
"TIME,D1,D2", "09/30/1973_24:00,1,2" | .\bin\ArrayMath.exe -d 1 2 -rn -cn -a - - 1
```

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0
bin\ArrayMath.exe -d 4 3 -a data.dat weights.dat 0.5
```

### Multiply Current Result

`-m value_or_file`, `--multi value_or_file`

Multiplies the current result. If the argument starts with `*`, the value after `*` is parsed as a scalar. Otherwise the argument is treated as a file containing an array with the current shape.

Examples:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -m *10
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -m weights.dat
```

### Output Format

`-fm format`, `--fmt format`

Sets the Fortran format used to write numeric output. The default is:

```text
(*(G0.8,x))
```

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -fm (3F12.4)
```

### Line Endings

`--lf`, `-lf`

Forces LF (`\n`) line endings for output to stdout or a file. By default, ArrayMath uses the Fortran compiler's normal output behavior.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 --lf output.dat
```

### Offset

`-o value`, `--offset value`

Adds a scalar offset to the current result.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -o -10
```

### Duplicate Rows

`-dr count`, `--duplicate count`

Duplicates the current rows `count` times.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -dr 2
```

### Skip Rows While Reading

`-sr count`, `--skiprow count`

Sets the number of rows to skip when reading subsequent input files. This option must appear before the `-a` or `-m` option that reads the file.

Example:

```bat
bin\ArrayMath.exe -d 100 5 -sr 1 -a data_with_header.dat - 1.0
```

### Skip Columns While Reading

`-sc count`, `--skipcol count`

Sets the number of columns to skip when reading subsequent input files. This option must appear before the `-a` or `-m` option that reads the file.

Example:

```bat
bin\ArrayMath.exe -d 100 5 -sc 2 -a data_with_prefix_columns.dat - 1.0
```

### Row Names

`-rn`, `--rowname`

Enables reading row names from the first column after skipped columns. Row names are useful for sorting rows, grouping by row name, and preserving labels after subsetting or stacking.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -rn -a table.dat - 1.0
```

### Column Names

`-cn`, `--colname`

Enables reading column names from the first row after skipped rows. Column names are useful for filtering and sorting columns.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -cn -a table.dat - 1.0
```

### Function

`-x function`, `--func function`

Applies a named function to the current result. See the function reference below.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -x mean
```

### Group By

`-g column_or_index function`, `--groupby column_or_index function`

Groups rows by a column and applies an aggregation. Supported group functions are:

```text
min, max, mean, sum, std, centralize
```

`column_or_index` can be a column name or a 1-based column index. If it resolves to index `0`, ArrayMath groups by row names.

Examples:

```bat
bin\ArrayMath.exe -d 4 3 -a grouped.dat - 1.0 -g 1 mean
bin\ArrayMath.exe -d 4 3 -cn -a grouped_named.dat - 1.0 -g layer sum
```

`centralize` subtracts the group mean from every row in the original array rather than reducing to one row per group.

### Moving Average

`-ma window decay`, `--moveavg window decay`

Computes a moving average along rows for each column.

`window` is the number of rows in the moving window.

`decay` controls exponentially weighted moving average behavior:

- `0` gives uniform weights, equivalent to a simple moving average.
- `1` uses only the most recent row in each window.
- Values between `0` and `1` create exponential decay.

The first `window - 1` rows are written as `NaN`.

Example:

```bat
bin\ArrayMath.exe -d 100 2 -a series.dat - 1.0 -ma 5 0
```

### Stack

`-st`, `--stack`

Stacks the 2D array into one column. Values are emitted in row-major command-output order.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -st
```

### Power

`-p value`, `--power value`

Raises every current result value to a scalar power.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -p 2
```

### Clip

`-c vmin vmax`, `--clip vmin vmax`

Clips values to the interval `[vmin, vmax]`.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -c 0 1
```

### Subset

`-s selector`, `--subset selector`

Subsets rows or columns. Selectors begin with `r` for rows or `c` for columns.

Slice syntax:

```text
rfirst:last
cfirst:last
```

List syntax:

```text
r1,3,5
c1,3,5
```

Examples:

```bat
bin\ArrayMath.exe -d 10 5 -a data.dat - 1.0 -s r1:5
bin\ArrayMath.exe -d 10 5 -a data.dat - 1.0 -s c1,3,5
```

### Head and Tail

`-hd count`, `--head count`

Keeps the first `count` rows of the current array.

`-tl count`, `--tail count`

Keeps the last `count` rows of the current array. Counts larger than the current
number of rows keep the entire array. Both operations are applied in command-line
order, like `--subset`.

Examples:

```bat
bin\ArrayMath.exe -d 100 5 -a data.dat - 1.0 --head 10
bin\ArrayMath.exe -d 100 5 -a data.dat - 1.0 --tail 10
```

### Unique and Reverse

`-un`, `--unique` keeps the first occurrence of each distinct numeric row.
Row names do not affect which rows are duplicates; the retained row keeps its name.

`-rv`, `--reverse` reverses the current row order, including row names.
Both switches are applied in command-line order with other operations.

```bat
bin\ArrayMath.exe -d 100 5 -a data.dat - 1.0 --unique --reverse
```

### Filter

`-f expression`, `--filter expression`

Filters rows using a column name or 1-based column index. Supported comparisons are:

```text
<, <=, >, >=, ==, /=
```

Examples:

```bat
bin\ArrayMath.exe -d 100 5 -cn -a table.dat - 1.0 -f time>=3
bin\ArrayMath.exe -d 100 5 -a table.dat - 1.0 -f 2>0
```

### Transpose

`-t`, `--transpose`

Transposes the current array. Row and column names are swapped when present.

Example:

```bat
bin\ArrayMath.exe -d 4 3 -a data.dat - 1.0 -t
```

### Verbose

`-v`, `--verbose`

Prints progress messages.

### Help

`-h`, `--help`

Prints the built-in help message.

### MODFLOW Binary Placeholders

`-mb`, `--mfbin`

Placeholder for reading MODFLOW binary files. This is currently marked TODO in the source.

`-md`, `--mfdbin`

Placeholder for reading MODFLOW binary files in double precision. This is currently marked TODO in the source.

## Function Reference

Functions are used with `-x` or `--func`.

### Element-wise Functions

These functions preserve the current array shape:

| Function | Description |
| --- | --- |
| `abs` | Absolute value |
| `exp` | Exponential |
| `log10` | Base-10 logarithm |
| `log` | Natural logarithm |
| `sqrt` | Square root |
| `sinh` | Hyperbolic sine |
| `cosh` | Hyperbolic cosine |
| `tanh` | Hyperbolic tangent |
| `sin` | Sine |
| `cos` | Cosine |
| `tan` | Tangent |
| `asin` | Arcsine |
| `acos` | Arccosine |
| `atan` | Arctangent |
| `int` | Convert values to integer by truncation |
| `nint` | Round values to nearest integer |
| `floor` | Greatest integer less than or equal to each value |
| `inverse` | Reciprocal, `1 / value` |
| `fraction` | Fortran `fraction` intrinsic |
| `cbrt` | Cube root preserving sign |
| `cumsum` | Cumulative sum down rows for each column |
| `transpose` | Same as `-t` |

### Difference Functions

`diff`

Computes row-to-row differences:

```text
row_i = row_i - row_(i-1)
```

The first row remains unchanged.

`diff1`

Subtracts the first row from every following row and sets the first row to zero.

### Column Reductions

These functions reduce the array to one row, computing one value per column. They ignore `NaN` values.

| Function | Description |
| --- | --- |
| `max` | Column maximum |
| `min` | Column minimum |
| `sum` | Column sum |
| `std` | Column standard deviation |
| `mean` | Column mean |

### Sorting Functions

`sortr`, `sort`, `sortrow`

Sort rows by row name.

`sortc`, `sortcolumn`

Sort columns by column name.

## Notes and Current Limitations

- `-d` must be supplied before operations that need array allocation.
- Options are applied immediately in the order they appear.
- Text input accepts comma-, tab-, or space-separated fields. Row and column names are read as text; numeric values use Fortran list-directed input. Quoted CSV fields containing commas or spaces are not supported.
- Column and row selectors use 1-based indexing.
- `matinv` and `dot` are currently disabled/commented in the source.
- MODFLOW binary options are placeholders and are not implemented yet.
